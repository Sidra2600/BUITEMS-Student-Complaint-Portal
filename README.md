# BUITEMS Student Complaint Portal

A responsive web-based campus support and ticketing system designed to streamline communication between students, faculty staff, and administration[cite: 6, 11].

## About the Project
This project is developed as part of our academic coursework at BUITEMS. It provides a clean, role-based workflow where students can report issues, administrators can assign tasks to relevant department experts, and staff can manage and resolve tickets efficiently[cite: 6].

## Key Features
* **Role-Based Workflows:** Distinct interfaces and permissions for Students, Staff, and Administrators[cite: 6].
* **Campus Support Categories:** Grouped departments and campus service categories[cite: 3, 6, 13].
* **Visual Identity:** Styled in accordance with official BUITEMS brand colors (Deep Blue `#0A2A5E` and Gold `#FFC72C`)[cite: 3, 8, 11].
* **Evidence Uploads:** Built-in photo attachment and compression features for accurate reporting[cite: 6].

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript[cite: 6, 11]
* **Backend Integration:** PHP & MySQL / XAMPP local server support[cite: 2, 7, 11]
